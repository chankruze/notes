## Repository Requirements

Create a public GitHub repository and submit the repository URL.

The repository should contain:

- Source code
- `README.md`
- Proper commit history
- Clear project structure

---
## README Requirements

The README should include:

### Project Setup

```bash
npm install
npm run dev
```

### Tech Stack

Example:

- React
- React Router
- Axios
### Project Structure

Briefly explain the folder structure and major architectural decisions.

### Assumptions

Document any assumptions made during implementation.

---
## Submission Checklist

- [ ]  Posts listing page completed
- [ ] Post details page completed
- [ ]  Comments displayed
- [ ]  User names displayed
- [ ]  Axios used for API requests
- [ ]  Loading states implemented
- [ ]  Error handling implemented
- [ ]  Responsive UI
- [ ]  README included

---
## Important Notes

- Focus on clean, maintainable code.    
- Prioritize correctness over visual design.
- Use reusable components wherever appropriate.
- Avoid unnecessary libraries unless justified.
- Do not hardcode API responses.
- Follow React best practices.
- Use meaningful commit messages.

---
## Submission Format

Submit:

1. GitHub Repository URL
2. Live Demo URL
3. Any additional notes or assumptions
