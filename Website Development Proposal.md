# Project Overview

Design and develop a modern, professional company portfolio website that reflects the firm's experience, credibility, and expertise in railway civil construction. The website will showcase completed projects, services, credentials, and company achievements while providing an easy way for prospective clients to get in touch.

In addition, a professionally designed **Company Profile PDF** will be created, suitable for sharing with government departments, private clients, and during tender discussions.

The website will be fully responsive, SEO-friendly, and built using modern static site technologies to ensure excellent performance, security, and long-term reliability.

# Proposed Technology Stack

|Technology|Purpose|
|---|---|
|**Astro**|Static site generation for speed, SEO, and long-term maintainability|
|**Tailwind CSS**|Modern responsive UI styling|
|**GSAP + ScrollTrigger**|Smooth scroll animations and section reveals|
|**Lenis**|Smooth scrolling experience|
|**CountUp.js**|Animated statistics and achievements|
|**Cloudflare Pages**|Secure global hosting with CDN|
|**Cloudflare Turnstile + Formspree / Resend**|Secure contact form with spam protection|
|**Google Analytics 4 + Search Console**|Website traffic and SEO monitoring|
